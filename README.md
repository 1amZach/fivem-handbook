# FiveM Handbook

A practical guide to writing modern FiveM resources in Lua: events and callbacks, server-side checks, ox_lib, state bags, permissions, saving data, performance, Svelte NUIs, connecting players and shipping a release.

It picks up where most beginner tutorials stop.

## Read it

**[1amzach.github.io/fivem-handbook](https://1amzach.github.io/fivem-handbook/)**

## Contributing

Spotted a mistake or want to add something? Pages are plain Markdown in `docs/guide`. Open an issue or a pull request.

To preview your changes locally:

```bash
npm install
npm run dev
```
